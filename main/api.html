Reservoir¶

class rctorch.Reservoir(model_cls: SNNBase, n_input: int, n_output: int, w_in_amp: float = 200.0, **model_kwargs)[source]¶

Reservoir computer with a spiking network as the hidden layer.

The input reaches the network through fixed random weights \(W_{in}\). The output is a linear readout of the network state \(r\) through trained weights \(W_{out}\):

\[I_{in} = W_{in} x, \qquad \hat{x} = W_{out}^T r\]
Parameters:
model_clstype[SNNBase]

Spiking network class for the hidden layer, such as LIF.

n_inputint

Dimension of the input signal.

n_outputint

Dimension of the output signal.

w_in_ampfloat, default 200.0

Amplitude of the input weights. Each entry of W_in is drawn uniformly from [-w_in_amp, w_in_amp].

**model_kwargs

Keyword arguments for model_cls.

Attributes:
modelSNNBase

The spiking network.

n_hiddenint

Number of neurons in model.

W_intorch.Tensor of shape (n_hidden, n_input)

Fixed input weights.

W_outtorch.nn.Parameter of shape (n_hidden, n_output)

Output weights with requires_grad=False. They start at zero, and fit_echo_state() or fit_force() sets them.

Pinvtorch.Tensor of shape (n_hidden, n_hidden) or None

Inverse correlation matrix that fit_force() updates. It is None until the first call to fit_force() and keeps its value between calls.

forward(x: Tensor, nt_transient: int = 500, closed_loop: bool = True)[source]¶

Run the reservoir and record its state.

The network first runs for nt_transient steps with zero input. It then runs one step per row of x. In open loop, the input at step i is x[i]. In closed loop, the input is the prediction \(\hat{x} = W_{out}^T r\), and x only sets the number of steps.

Parameters:
xtorch.Tensor of shape (nt, n_input)

Input signal.

nt_transientint, default 500

Number of steps to run with zero input before recording.

closed_loopbool, default True

If True, feed the prediction back as input instead of using x.

Returns:
s_rectorch.Tensor of shape (nt, n_hidden)

Network state at each step, recorded before the step’s update.

x_hat_rectorch.Tensor of shape (nt, n_input)

Prediction at each step. It stays all zeros in open loop.

Raises:
ValueError

If closed_loop is True and n_input differs from n_output.

fit_echo_state(x: Tensor, y: Tensor, nt_transient: int = 500, ridge_reg: float = 1e-05) → Tensor[source]¶

Train W_out with ridge regression on the open-loop states.

Runs forward() in open loop on x, collects the states \(S\), and sets

\[W_{out} = (S^T S + \lambda I)^{-1} S^T Y\]

where \(Y\) is y and \(\lambda\) is ridge_reg.

Input signal.

Target output.

Number of steps to run with zero input before recording.

ridge_regfloat, default 1e-5

Ridge regularization coefficient \(\lambda\).

Returns:
torch.Tensor of shape (nt, n_output)

Fitted output \(S W_{out}\).

fit_force(x: Tensor, nt_transient: int = 500, ridge_reg: float = 1.0, rls_step: int = 20, ff_coeff: float = 1.0) → Tensor[source]¶

Train W_out online with FORCE learning.

The reservoir runs in closed loop and feeds its prediction \(\hat{x}\) back as input. Every rls_step steps, a recursive least squares update moves W_out to reduce the error \(\hat{x} - x\). See _rls() for the update.

Parameters:
xtorch.Tensor of shape (nt, n_output)

Target signal for the prediction to follow.

nt_transientint, default 500

Number of steps to run with zero input before training.

ridge_regfloat, default 1.0

Regularization \(\alpha\) of the recursive least squares update. The first call starts Pinv at \(I / \alpha\). Later calls keep the existing Pinv and ignore this value.

rls_stepint, default 20

Number of steps between updates.

ff_coefffloat, default 1.0

Forgetting factor of the recursive least squares update, in the range (0, 1]. With 1.0, all past steps have equal weight.

Returns:
torch.Tensor of shape (nt, n_output)

Prediction at each step.

Raises:
ValueError

If n_input differs from n_output.

_rls(x: Tensor, x_hat: Tensor, state: Tensor, ff_coeff: float = 1.0)[source]¶

Apply one recursive least squares update to W_out and Pinv.

With \(P\) for Pinv, \(r\) for state, and \(\lambda\) for ff_coeff:

\[\begin{split}u &= P r \\ k &= \frac{u}{\lambda + r^T u} \\ e &= \hat{x} - x \\ P &\leftarrow \frac{P - k u^T}{\lambda} \\ W_{out} &\leftarrow W_{out} - k e^T\end{split}\]
Parameters:
xtorch.Tensor of shape (n_input, 1)

Target at the current step.

x_hattorch.Tensor of shape (n_input, 1)

Prediction at the current step.

statetorch.Tensor of shape (n_hidden, 1)

Network state that produced x_hat.

ff_coefffloat, default 1.0

Forgetting factor \(\lambda\). With 1.0, the memory is infinite.

Returns:
torch.Tensor of shape (n_input, 1)

The error \(e\).

Raises:
ValueError

If x, x_hat, or state has the wrong first dimension.

TypeError

If Pinv is None.

class rctorch.models.SNNBase(n_hidden: int, dt: float, device: device = device(type='cpu'), dtype: dtype = torch.float32)[source]¶

Base class for the spiking networks that form the hidden layer of a reservoir.

The base model integrates \(\dot{v} = -v + I\) with forward Euler steps. Subclasses replace mem_dot() and forward() with their own dynamics. Reservoir also expects a subclass to set N, the number of neurons, and to either set r or override state().

class rctorch.models.LIF(Ne: int, Ni: int, dt, BIAS: Tensor | ndarray | float = 80.0, tau_m: float = 50, tau_s: float = 20, gbar: float = 5, device: device = device(type='cpu'), dtype: dtype = torch.float32)[source]¶

Network of leaky integrate-and-fire neurons with exponential synapses.

The membrane potential \(v\) and synaptic output \(r\) of the neurons follow

\[\begin{split}\tau_m \dot{v} &= -v + I_{bias} + \bar{g} W r + I_{in} \\ \tau_s \dot{r} &= -r\end{split}\]

When \(v\) of a neuron crosses \(v_{th} = 30\) mV, it resets to \(v_{reset} = -20\) mV and \(r\) of that neuron grows by \(1 / \tau_s\). The model integrates both equations with forward Euler steps.

Parameters:
Neint

Number of excitatory neurons.

Niint

Number of inhibitory neurons.

dtfloat

Integration time step in ms.

BIAStorch.Tensor, np.ndarray, or float, default 80.0

Bias current \(I_{bias}\) in pA. Pass one value for all neurons or an array of shape (N, 1).

tau_mfloat, default 50

Membrane time constant \(\tau_m\) in ms.

tau_sfloat, default 20

Synaptic time constant \(\tau_s\) in ms.

gbarfloat, default 5

Coupling strength \(\bar{g}\).

devicetorch.device, default torch.device(“cpu”)

Device for the model’s tensors.

dtypetorch.dtype, default torch.float32

Data type for the model’s tensors.

Attributes:
Nint

Total number of neurons, Ne + Ni.

memtorch.Tensor of shape (N, 1)

Membrane potential \(v\) in mV. It starts at zero.

rtorch.Tensor of shape (N, 1)

Synaptic output, which the reservoir reads out. It starts uniformly random in [0, 1).

wtorch.Tensor of shape (N, N)

Recurrent weights \(W\), drawn from a normal distribution with mean 0 and standard deviation 1 / N.

Notes

Ne and Ni only set N. The weights do not depend on whether a neuron is excitatory or inhibitory.

class rctorch.models.MorrisLecar(dt: float, BIAS: ndarray | Tensor | float, Ne: int = 20, Ni: int = 20, C: float = 20, g_L: float = 2, g_K: float = 8, g_Ca: float = 4.4, E_L: float = -60, E_K: float = -84, E_Ca: float = 120, v1: float = -1.2, v2: float = 18, v3: float = 2, v4: float = 30, phi: float = 0.04, a_r: float = 1.1, a_d: float = 0.02, v_t: float = 2, k_p: float = 5, t_max: float = 1.0, E_AMPA: float = 0, E_GABA: float = -75, gbar: float = 1, device: device = device(type='cpu'), dtype: dtype = torch.float32)[source]¶

Network of Morris-Lecar neurons with conductance-based synapses.

The model updates all \(N\) neurons at once with tensor operations and forward Euler steps. See the Notes section for the equations.

Parameters:
dtfloat

Integration time step in ms.

BIASnp.ndarray, torch.Tensor, or float

Bias current \(I_{bias}\) in pA. Pass one value for all neurons or an array of shape (N, 1).

Number of excitatory neurons. Their synapses use the reversal potential E_AMPA.

Niint, default 20

Number of inhibitory neurons. Their synapses use the reversal potential E_GABA.

Membrane capacitance \(C\). It divides the total current, so it also sets the time scale of \(v\).

Leak conductance \(g_L\).

Potassium conductance \(g_K\).

g_Cafloat, default 4.4

Calcium conductance \(g_{Ca}\).

Reversal potential of the leak current in mV.

E_Kfloat, default -84

Reversal potential of the potassium current in mV.

E_Cafloat, default 120

Reversal potential of the calcium current in mV.

Midpoint \(v_1\) of \(m_\infty\) in mV.

v2float, default 18

Slope \(v_2\) of \(m_\infty\) in mV.

Midpoint \(v_3\) of \(n_\infty\) and \(\tau_n\) in mV.

v4float, default 30

Slope \(v_4\) of \(n_\infty\) and \(\tau_n\) in mV.

Slope \(k_p\) of \(T(v)\) in mV.

Maximum \(T_{max}\) of \(T(v)\).

Reversal potential of excitatory synapses in mV.

E_GABAfloat, default -75

Reversal potential of inhibitory synapses in mV.

gbarfloat, default 1

Synaptic conductance \(\bar{g}\) in nS.

devicetorch.device, default torch.device(“cpu”)

Device for the model’s tensors.

Data type for the model’s tensors.

Attributes:
Nint

Total number of neurons, Ne + Ni.

memtorch.Tensor of shape (N, 1)

Membrane potential \(v\) in mV. It starts at zero.

ntorch.Tensor of shape (N, 1)

Potassium gating variable. It starts uniformly random in [0, 1).

storch.Tensor of shape (N, 1)

Synaptic gating variable, which the reservoir reads out. It starts at zero.

wtorch.Tensor of shape (N, N)

Boolean connectivity \(w\). Each entry is True with probability 2 / N.

Notes

The membrane potential follows

\[C \dot{v} = I_{bias} + I_L + I_K + I_{Ca} + I_{in} + I_{syn}\]

with the ionic currents

\[\begin{split}I_L &= -g_L (v - E_L) \\ I_K &= -g_K n (v - E_K) \\ I_{Ca} &= -g_{Ca} m_\infty(v) (v - E_{Ca})\end{split}\]

The gating variables follow

\[\begin{split}\dot{n} &= \frac{n_\infty(v) - n}{\tau_n(v)} \\ \dot{s} &= \alpha_r T(v) (1 - s) - \alpha_d s\end{split}\]

where

\[\begin{split}m_\infty(v) &= \frac{1}{2} \left[1 + \tanh\left(\frac{v - v_1}{v_2}\right)\right] \\ n_\infty(v) &= \frac{1}{2} \left[1 + \tanh\left(\frac{v - v_3}{v_4}\right)\right] \\ \tau_n(v) &= \frac{1}{\phi \cosh\left(\frac{v - v_3}{2 v_4}\right)} \\ T(v) &= \frac{T_{max}}{1 + \exp\left(-\frac{v - v_t}{k_p}\right)}\end{split}\]

The synaptic current into neuron \(i\) is

\[I_{syn,i} = -\bar{g} \sum_{j=1}^{N} w_{ij} (v_i - E_j) s_j\]

where \(E_j\) is E_AMPA if neuron \(j\) is excitatory and E_GABA if it is inhibitory. All outgoing synapses of a neuron share its reversal potential, so the network follows Dale’s law.

class rctorch.models.MorrisLecarCurrent(dt: float, BIAS: ndarray | Tensor | float, Ne: int = 20, Ni: int = 20, C: float = 20, g_L: float = 2, g_K: float = 8, g_Ca: float = 4.4, E_L: float = -60, E_K: float = -84, E_Ca: float = 120, v1: float = -1.2, v2: float = 18, v3: float = 2, v4: float = 30, phi: float = 0.04, a_r: float = 1.1, a_d: float = 0.02, v_t: float = 2, k_p: float = 5, t_max: float = 1.0, E_AMPA: float = 0, E_GABA: float = -75, gbar: float = 1, device: device = device(type='cpu'), p_sparsity: float = 1.0)[source]¶

Morris-Lecar network with current-based synapses and normally distributed weights.

The neurons follow the same dynamics as in MorrisLecar, but the synaptic current into neuron \(i\) has no reversal potentials:

\[I_{syn,i} = -\bar{g} \sum_{j=1}^{N} w_{ij} s_j\]

where \(w_{ij}\) is the weight from neuron \(j\) to neuron \(i\). The sign of each weight, not the neuron type, decides whether a synapse excites or inhibits. A neuron can have outgoing synapses of both signs, so the network does not follow Dale’s law. For other connectivity, assign your own weights to w.

The model takes the same parameters as MorrisLecar, plus p_sparsity. It has no dtype parameter and always uses float32. Ne and Ni only set N.

Parameters:
p_sparsityfloat, default 1.0

Sets the standard deviation of the weights to \(1 / \sqrt{N p}\), where \(p\) is p_sparsity. The weights stay dense.

Attributes:
wtorch.Tensor of shape (N, N)

Recurrent weights \(w\), drawn from a normal distribution with mean 0 and standard deviation \(1 / \sqrt{N p}\).

calc_ipsc() → Tensor[source]¶

Return the current-based synaptic current \(I_{syn} = -\bar{g} w s\), of shape (N, 1).

class rctorch.HyperChaoticAttractor(T: float, dt: float, tau: float)[source]¶

class rctorch.BruteForceMesh(reservoir_kwargs: dict, train_kwargs: dict, test_kwargs: dict, params: dict[str, ndarray], num_threads: int = 4)[source]¶

Grid search over reservoir parameters.

Builds every combination of the values in params, trains one reservoir per combination with FORCE learning, tests it, and saves the results to disk. The simulations run in a thread pool.

Parameters:
reservoir_kwargsdict

Fixed keyword arguments for Reservoir. They override entries of params with the same name.

train_kwargsdict

Keyword arguments for fit_force().

test_kwargsdict

Keyword arguments for forward() in the test phase.

paramsdict of str to np.ndarray

Parameter names mapped to 1D arrays of the values to try.

num_threadsint, default 4

Maximum number of simulations that run at the same time.

run(save_dir: str) → None[source]¶

Run one simulation per parameter combination and save each result.

Each simulation writes to its own subdirectory of save_dir, named after its parameter values with dots replaced by p. For example, w_in_amp=20, gbar=10 gives w_in_amp_20p0000_gbar_10p0000. The subdirectory holds reservoir_params.json, output_data_train.npy, and output_data_test.npy.

Parameters:
save_dirstr

Directory to save the results in.

Notes

This method waits for every simulation but does not re-raise their errors. A simulation that fails during training or testing prints its error. A simulation that fails while saving prints nothing.
